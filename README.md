## 📌 About the Project

**Social Chat** is a web-based chatting application designed for local users to connect with other people and communicate through online chat.

Users can register, log in, find other users, and start one-to-one conversations through a simple and user-friendly interface.

The project is developed using modern web technologies and provides an easy way for local users to connect and chat.

---

## ✨ Features

* 👤 User Registration and Login
* 🔍 Find and view other users
* 💬 One-to-one private chatting
* 📩 Send and receive messages
* 👥 Connect with local users
* ⚡ Fast and interactive chat experience
* 📱 User-friendly and responsive interface
* 🔐 User authentication

---

## 🛠️ Technologies Used

* **Frontend:** React.js, JavaScript, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Real-Time Communication:** Socket.IO
* **Deployment:** Render

---

## ⚙️ How the Application Works

1. User opens the **Social Chat** application.
2. User creates an account or logs in.
3. After login, users can view other registered users.
4. User selects a person they want to chat with.
5. A private chat window is opened.
6. Users can send and receive messages.
7. Messages are communicated between users through the chat system.

### 🔄 Application Flow

```text
Register / Login
       ↓
   View Users
       ↓
 Select User
       ↓
  Start Chat
       ↓
Send / Receive Messages
```
